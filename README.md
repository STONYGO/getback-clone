# GetBack Clone — 姿勢モニター

東北大学で開発されているGetbackの挙動を再現したクローン。カメラ映像から姿勢を推定し、崩れると画面の四隅が赤く、正しい姿勢に戻すと緑になり、規定時間キープすると元の画面に戻る。映像は端末内でのみ処理し、送信・保存はしない。

## 構成
| 版 | 用途 | 場所 |
|---|---|---|
| Web版 | iPhone / iPad / PCブラウザ（ページ表示中のみ） | `index.html`（GitHub Pages） |
| デスクトップ版 | Mac / Windows 常駐。**PC画面全体**の四隅が色付く | `desktop/` |

## デスクトップ版の入手
GitHub → Actions → 「Build desktop app」→ 最新の実行 → Artifacts から
- Mac: `GetBack-macOS`（.dmg）
- Windows: `GetBack-Windows`（インストーラ .exe / ポータブル .exe）

署名なしのため初回のみ：
- Mac：アプリを右クリック →「開く」。カメラ許可を求められたら「OK」
- Windows：SmartScreenで「詳細情報」→「実行」

## 使い方（デスクトップ版）
1. 起動するとカメラが開始し、初回はキャリブレーション（正しい姿勢で4秒静止）
2. 以後はウィンドウを閉じてOK。メニューバー（Mac）／タスクトレイ（Windows）に常駐し計測を続ける
3. 姿勢が崩れると全ディスプレイの四隅が赤く点滅し、上部に理由を表示。戻すと緑＋キープバー → 消灯
4. トレイメニュー：監視の開始/停止、再キャリブレーション、ログイン時自動起動、終了

オーバーレイはクリック透過のため、作業の邪魔にはならない。

## 判定指標
首の傾き／うつむき／画面との距離（前のめり）／首の沈み込み（猫背）／肩の傾き。
キャリブレーション時の値と揺らぎから許容幅を自動決定。感度・猶予時間・保持時間は設定で調整。

## 開発
```
cd desktop && npm install && npm start
```
