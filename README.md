# Posture Lab — GetBack Clone / KAMAE Lite / KAMAE AI

Webカメラで姿勢を見守り、崩れると**画面の四隅だけ**がそっと色づく姿勢モニター。
GetBack（背骨計）の特許方式を実験的に再現したものと、それを回避した2製品の、合計3製品を比較検証するための実験用リポジトリです。

| 製品 | 方式 | 必要な映り方 | AI |
|---|---|---|---|
| **GetBack Clone**（`getback/`） | 頭部角度＋視距離 → 2次回帰で脊柱5角度を推定（特許方式の実験再現・回帰係数は仮値） | 顔 | なし |
| **KAMAE Lite**（`kamae/`） | 肩基準の体座標のみ。視距離・頭部角度・脊柱推定を使わない回避設計 | 両肩と胸の上部 | なし |
| **KAMAE AI**（`kamae-ai/`） | KAMAE Liteの方式に加え、端末内AIが使用中に個人の構えを学習し、崩れの予兆を30秒前に検知 | 両肩と胸の上部 | 端末内AI＋任意のAIコーチ |

## 共通機能
- 背景常駐：起動後はメニューバー／タスクトレイに常駐し、ウィンドウは初回とキャリブレーションのときだけ表示
- 四隅の表示：崩れると赤 → 戻すと緑 → キープで消灯。濃さは「控えめ／標準／はっきり」から選べ、理由の文字表示はオフが既定
- キャリブレーション：4秒間の静止計測。ブレがあれば再計測し、登録時の肩の傾きもチェックする
- 傾きの癖（未病のサイン）：肩の高さの左右差・上体や首の左右の傾きが、一定方向に続いていないかを日単位で判定し、続く場合は整形外科での相談を案内する
- レポート：日次・月次・3か月を Slack／メール／Googleカレンダーへ配信（[設定方法](docs/REPORTS.md)）
- プライバシー：映像は端末内でのみ処理。記録は端末内に保存し、配信するのは集計値だけ

## 使い方
### Web版（スマホ・iPad・PCブラウザ。ページを開いている間だけ動作）
GitHub Pages：`https://stonygo.github.io/getback-clone/` から製品を選ぶ

### デスクトップ版（PC画面全体の四隅表示・背景常駐）
[Actions](../../actions/workflows/desktop.yml) → 最新の成功した実行 → Artifacts から次のものをダウンロードする。

- `getback-Windows`／`kamae-Windows`／`kamae-ai-Windows`：インストーラ版とポータブル版の .exe
- `*-macOS`：.dmg

署名なしのため、初回のみ次の操作が必要です。
- Windows：「詳細情報」→「実行」
- Mac：アプリを右クリック →「開く」→ カメラを許可

### 動作テストの手順
1. 起動し、カメラを許可する。キャリブレーションで良い姿勢のまま4秒静止する
2. ウィンドウが自動で閉じ、トレイに常駐したことを確認する
3. うつむく（GetBack Clone）、または肩をすくめる・上体を傾ける・頭を前に出す（KAMAE）を2秒続け、四隅が赤くなることを確認する
4. 姿勢を戻すと緑になり、3秒キープで消えることを確認する
5. 画面に近づく・離れるだけでは、KAMAEが反応しないことを確認する（回避設計の検証）
6. KAMAE AI：ゆっくり崩していくと、赤の前に琥珀色（予兆）が灯ることを確認する
7. レポートタブで配信先を設定し、「日次を送信」を押す

## 開発
```
python3 tools/build-pages.py           # tools/template.html から3製品のページを生成
cd desktop && npm install
PRODUCT=kamae-ai npm start             # getback | kamae | kamae-ai
```
