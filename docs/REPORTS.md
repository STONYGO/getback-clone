# レポート配信の設定（Slack・メール・カレンダー）

アプリ内の「レポート」タブで配信先を設定します。映像は送られず、集計値だけが送られます。

## 配信内容
| 種類 | タイミング | 内容 |
|---|---|---|
| 日次ふりかえり | 毎日、設定時刻（初期値18:00）以降に1回 | 良い姿勢率・前日比、計測時間、警告回数、崩れやすい時間帯、多かった崩れ方 |
| 月次レポート | 毎月はじめ（最初の配信タイミング）に前月分 | 上記に加え、計測日数、ベストの日 |
| 3か月レポート | 1・4・7・10月に前3か月分 | 同上 |
| 傾きの癖 | 各レポートに自動で付記 | 肩の高さの左右差・上体／首の左右の傾きが、一定方向に続いている場合の指摘と受診のおすすめ |

- アプリ（デスクトップ版は背景常駐）が起動している間に配信されます。配信時刻にPCが閉じていた場合は、次に起動したときに送られます。
- 「今すぐ送信」ボタンで、日次・直近30日・直近90日のレポートを手動で送れます。
- KAMAE AIでは、Claude APIキーを設定すると、AIコーチのコメントがレポートに付きます（任意）。

## 1. Slack
1. https://api.slack.com/apps →「Create New App」→「From scratch」
2. 「Incoming Webhooks」をオンにし、「Add New Webhook to Workspace」で投稿先チャンネルを選ぶ
3. 表示された `https://hooks.slack.com/services/...` をアプリの「Slack Incoming Webhook URL」に貼る

## 2. メール＋Googleカレンダー（Google Apps Script（GAS））
1. https://script.google.com で新規プロジェクトを作り、`integrations/google-apps-script/Code.gs` の内容を貼り付ける
2. `SECRET` を任意の文字列に変更する
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。実行ユーザーは「自分」、アクセスできるユーザーは「全員」
4. 権限を承認し、発行された `.../exec` のURLをアプリに貼る。「GAS 共有シークレット」には手順2の値を入れる
5. メール送信先を空欄にすると、GASを作ったGoogleアカウント宛てに届く。カレンダーは既定のカレンダーに15分の予定として登録される

## 3. AIコーチ（KAMAE AIのみ・任意）
- Anthropic Console で発行したAPIキーを入力します。送るのは集計値（良い姿勢率・時間帯・傾きの癖の有無など）だけで、映像や生の特徴量は送りません。
- 検証用の簡易実装のため、キーは端末内（ブラウザ／アプリのローカル保存領域）に保存されます。共用PCでは使わないでください。
